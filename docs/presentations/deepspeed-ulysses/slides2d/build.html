Takeaway

Ulysses makes sequence length a parallel dimension.

sequence shards across GPUs

heads split

ordinary, per head

TOK

tokens back

Best use case?

Extremely long sequences, where one example is the bottleneck.

Main cost?

A fast all-to-all interconnect (NVLink / InfiniBand).

Main limit?

P must divide the number of attention heads.
