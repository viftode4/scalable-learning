08 · FINAL TAKEAWAYThe slide to remember
One-line answer

Ulysses makes sequence length a parallel dimension.

TOK

tokens split

sequence shards across GPUs

HEAD

heads split

all-to-all regroups activations

ATTN

attention

ordinary local attention per head group

TOK

tokens back

all-to-all returns to sequence layout

Best use case?Extremely long sequences where one example is the bottleneck.
Main cost?Fast all-to-all communication is required.
