03 · THE IDEASequence-parallel ↔ head-parallel
Ulysses in one sentence

Split tokens across GPUs, then all-to-all into head-parallel attention.

The model still computes ordinary full attention. Ulysses just changes which GPU owns which slice at each moment.

04 · MENTAL MODELWhat each GPU sees during attention

During attention, one GPU sees the full sequence plane

But only for a subset of heads, so the computation remains partitioned.

Why this helps adoption

Attention kernels stay local.

  • Q/K/V projections start sequence-parallel.
  • All-to-all converts sequence shards into head shards.
  • Dense, sparse, causal, or FlashAttention runs as a local kernel.
  • A second all-to-all returns the layout for MLP and layer norm.

12 · CRITIQUEWhere the result is strongest—and where to be careful
Critical reading

This is a systems win with real assumptions.

  • All-to-all performance depends heavily on the network fabric.
  • Sequence-parallel degree is bounded by attention heads.
  • The “constant communication” story assumes N and P scale together.
  • Later context-parallel methods raise the question: combine or replace?
13 · TAKEAWAYThe slide to remember
Main takeaway

Ulysses makes sequence length a first-class parallel dimension.

Its key contribution is not a new attention approximation. It is a layout transformation that lets existing attention kernels operate locally while the sequence is distributed globally.

Headline: 2.5× faster training · 4× longer sequences · 10× less communication
