The sharp limit

P must divide the number of heads.

Sequence-parallel degree P assigns whole heads to GPUs. If P > h, a GPU gets no head — the method can't run. (An implementation requirement, not a theorem.)

Bonus · Q&A — memory partitioning

ZeRO: store a slice, borrow the rest, then give it back.

ZeRO-3 shards parameters across the data-parallel group: each GPU keeps 1/D, all-gathers a layer just-in-time, computes, then frees it. shard → gather → compute → free.

Ulysses spreads model state across all Ps×Pd devices. On a 2×2 grid each card holds 1/4 of the weights — vs 1/2 for data-parallel ZeRO-3 alone.
